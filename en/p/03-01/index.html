Kryptos ↔ шифрование

Art

Artist
Jim Sanborn
Work
Kryptos
Year
1990
Where
CIA headquarters courtyard, Langley

A copper sculpture with about 1,800 cipher characters stands in the CIA courtyard. Three parts are solved, the fourth officially is not.

↔

Code

end-to-end encryption

Everyone can see the Kryptos cipher; only the key holder can read it. End-to-end encryption works the same way: the server carries your message but sees only symbols.

Action

Turn on end-to-end encryption in your messenger if it is off.

Включите сквозное шифрование в мессенджере, если оно выключено.

The label in the room

The same hash is printed at the foot of the label. If they match, nobody changed the text.

Everyone sees the Kryptos cipher; no one has read its fourth part. End-to-end encryption works the same way: the server sees only symbols. Turn it on in your messenger.
