Менкман сделала из сбоев изображения искусство и написала его манифест. Аркенджел перепаял картридж «Марио» так, что в игре остались одни облака.

↔

Код

уязвимость

Уязвимость — та же ошибка, которой кто-то воспользовался. В 2014 году ошибка Heartbleed в OpenSSL позволяла читать чужую память с серверов по всему миру. Обновление — это заплатка.

Действие

Ставьте обновления в тот же день, когда они пришли.

Install updates the day they arrive.

Этикетка в зале

Тот же хеш напечатан внизу этикетки. Совпадает — текст никто не менял.

Художники делают из сбоев искусство. Хакеры делают из сбоев отмычки: так ошибка Heartbleed в 2014 году открыла память серверов. Ставьте обновления в тот же день, когда они пришли.

Artists turn errors into art. Attackers turn them into lock picks: in 2014 Heartbleed opened server memory. Install updates the day they arrive.
